# ClearPATH US GitHub Pages Site

Static website for ClearPATH US.

## Publish on GitHub Pages
1. Create a GitHub repository (for example `clearpath-us-site`).
2. Upload all files in this folder to the repository root.
3. In GitHub: **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder, then save.
6. GitHub will provide a `github.io` URL.

## Custom domain
To use `clearpath.us.com`, add the domain in GitHub Pages settings, then configure the DNS records with the company that controls the domain. GitHub's exact DNS values can change, so use the values GitHub shows in the Pages settings at the time you connect the domain.
